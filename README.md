## 🎨 Modern Architecture & Aesthetic

Inspired by modern developer portfolios like [lakyar.com](https://lakyar.com/), featuring:
- **Framework & Tooling**: Built with **React 19**, **Vite**, **TypeScript**, and **Tailwind CSS v4**.
- **Icons & Visuals**: **Lucide React** icon system and custom obsidian/glassmorphic styling.
- **Dynamic Features**:
  - **Floating Glassmorphic Header**: Blur-backdrop navigation pill with responsive mobile drawer.
  - **Status Pill & Portrait Card**: Glowing ambient halo with real high-resolution portrait and live availability badge.
  - **Impact Metric Counters**: Quick impact badges (6+ Projects, HND Merit, BSc Candidate, 100% Agile Delivery).
  - **Infinite Marquee Tech Ticker**: Continuous animated tape showcasing developer tags and tools.
  - **Categorized Technical Arsenal**: 4 shadcn-style cards grouping AI/Agents, Backend, Frontend/Mobile, and SDLC practices.
  - **Interactive Project Filtering**: Live filtering tabs (`All`, `AI & Agents`, `Full Stack`, `Frontend / Mobile`) with repository and live demo links.
  - **Academic & Transferable Background**: Dual-column timeline showcasing HND Software Engineering, BSc Computing, and Civil Engineering / Retail leadership discipline.
  - **Download Center**: Direct downloads for verified PDF Portfolio and Word DOCX CV.
  - **Interactive Contact Box**: Click-to-copy email address with toast feedback and direct mail client integration.

## 🛠️ Local Development & Build

The source code for the application is located in the `app/` directory:

```bash
# 1. Navigate to the app directory
cd app

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Compile production build
npm run build
```

The production bundle is copied directly to the repository root for seamless hosting via **GitHub Pages**.
