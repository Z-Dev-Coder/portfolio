## 🛠️ Features & Stack

- **Tech Stack**: HTML5, Tailwind CSS, Modern JavaScript
- **Design**: Dark glassmorphism layout, responsive card grids, glowing portrait halo
- **Sections**:
  - Hero with live career status badge
  - Technical Competency Grid (Backend, AI/Agents, Frontend)
  - Featured Project Cards with GitHub repository links
  - Career Experience & Academic Education Timeline
  - Direct 1-Click Email & Clipboard actions
- **Hosting**: Deployed directly via GitHub Pages
